# 桌面歌词浮窗

一个 EchoMusic 插件：在桌面上显示一个可自定义的独立歌词浮窗，支持调整**字体样式、字号、已播放/未播放歌词颜色**与**翻译**。

## 功能

- 桌面独立浮窗，透明背景、可拖动、可缩放、可贴边（默认在屏幕底部居中）。
- **字体样式**：跟随系统或从系统字体列表中选择。
- **字号**：12–72px 无级调节（浮窗内也有 `±` 快捷按钮）。
- **已播放 / 未播放歌词颜色**：分别设置两种颜色，已播行与当前行用“已播放色”，后续行用“未播放色”，对比一目了然。
- **当前行强调**：可选当前行加粗放大。
- **翻译**：歌词下方显示译文（歌曲有翻译数据时）。
- **对齐 / 行距 / 背景**：支持居中或居左、行距调节，以及玻璃背景的不透明度与模糊。
- **置顶 / 鼠标穿透**：浮窗可常驻置顶，或开启鼠标穿透用作纯展示。

## 安装

方式一（本地）：
1. 在 EchoMusic「插件管理」中点击“打开目录”，进入本地插件目录。
2. 把本文件夹（`desktop-lyric-styler/`，需含 `manifest.json`）复制进去。
3. 回到“插件管理”启用本插件，浮窗会自动弹出。

方式二（插件源）：将本仓库作为插件源添加后在线安装。

## 使用

- 浮窗顶部工具条（鼠标移上去显示）提供：减小/增大字号、翻译开关、置顶开关、隐藏浮窗。工具条也可拖动整个窗口。
- 在「插件管理」中找到“桌面歌词浮窗”的设置页，可调整字体、颜色、翻译、背景等全部参数；修改会实时同步到浮窗。

## 配置项（manifest / 设置）

| 项 | 说明 |
| --- | --- |
| `fontFamily` | 字体，`""` 表示跟随系统 |
| `fontSize` | 字号 12–72px |
| `playedColor` | 已播放歌词颜色 |
| `unplayedColor` | 未播放歌词颜色 |
| `showTranslation` | 是否显示翻译 |
| `align` | `center` / `left` |
| `boldCurrent` | 当前行加粗强调 |
| `lineHeight` | 行距 1.0–3.0 |
| `backgroundOpacity` | 背景不透明度 0–100% |
| `backgroundBlur` | 背景模糊 0–40px |
| `alwaysOnTop` | 窗口置顶 |
| `clickThrough` | 鼠标穿透 |

## 兼容性

依赖 `>=2.2.6-beta.20`（独立浮窗与 Now Playing 快照）。歌词行取 `lyric.lines[].text / translated`，翻译数据由主程序提供。
