# 桌面歌词浮窗

一个 EchoMusic 插件：在桌面上显示一个独立歌词浮窗，**默认复刻主程序（EchoMusic）自带桌面歌词的样式**——当前行大号 + 一行副歌词（译文或下一行），支持逐词平滑高亮，字体、字号、颜色、对齐均可调。

## 功能

- 桌面独立浮窗，透明背景、可拖动、可缩放、可贴边（默认在屏幕底部居中）。
- **两种布局**
  - **EchoMusic 风格（默认）**：只显示当前行（大号，已播放色）+ 一行副歌词（小号，未播放色）。副歌词优先显示译文，没有译文时显示下一行歌词。切行时上一行会向上滑动并放大，与主程序一致。
  - **整段歌词滚动列表**：居中显示全部歌词并自动滚动到当前行（旧版行为）。
- **字体样式 / 字号**：跟随系统或从系统字体列表中选择；字号下拉预设档位（12–72px，默认 40px）。
- **已播放 / 未播放歌词颜色**：默认 `#31cfa1` / `#7a7a7a`（主程序桌面歌词同款）。
- **逐词高亮（卡拉 OK）**：当前行按字词从左到右**平滑**填充高亮色（渐变 + `background-clip: text` 逐帧推进 `background-position`，非逐字跳变）。
- **翻译**：在歌词下方显示译文；无译文时可选择显示下一行。
- **对齐**：居中 / 居左 / 居右 / 左右交错（交错为主程序默认，奇偶行分别靠左、靠右）。
- **行距**、**背景不透明度与模糊**、**文字阴影**（主程序 normal 档）。
- **置顶 / 鼠标穿透 / 窗口锁定**。

## 安装

方式一（本地）：
1. 在 EchoMusic「插件管理」中点击“打开目录”，进入本地插件目录。
2. 把本文件夹（`desktop-lyric-styler/`，需含 `manifest.json`）复制进去。
3. 回到“插件管理”启用本插件，浮窗会自动弹出。

方式二（插件源）：将本仓库作为插件源添加后在线安装。

## 使用

- 功能按钮位于浮窗**内部右上角**的胶囊条中（鼠标移到浮窗上显示），提供：窗口锁定、隐藏浮窗。
- **拖动窗口请在歌词区按住拖动**（工具条不是拖拽热区）。锁定后整窗不可拖动，需先解锁。
- 在「插件管理」中找到“桌面歌词浮窗”的设置页，可调整布局、字体、颜色、对齐、翻译、背景等全部参数；修改会实时同步到浮窗。
- 若窗口仍是升级前的旧尺寸，拖一下窗口边缘调整即可（新默认 720×190）。

## 与主程序桌面歌词的对应关系

| 主程序 | 本插件 |
| --- | --- |
| 当前行 1em、下一行 0.8em、译文 0.72em | 同 |
| 行高 1.24、行内边距 4px、行间距 `clamp(round(fontSize×0.1), 3, 8)` | 同 |
| `playedColor` `#31cfa1` / `unplayedColor` `#7a7a7a` | 同（默认值） |
| 逐字填充：`linear-gradient(to right, 已播放 50%, 未播放 50%)` + `background-size: 200%` + `background-clip: text`，逐帧改 `background-position-x` | 同 |
| 文字阴影 normal 档 + 逐字 `drop-shadow` | 同 |
| 对齐 `both`（奇偶行左右交错） | 同（默认） |
| 注音（ruby）模式、竖排布局、歌词特效 | **未实现** |

## 配置项

| 项 | 说明 |
| --- | --- |
| `layoutMode` | `echo`（EchoMusic 风格，默认）/ `scroll`（整段滚动列表） |
| `fontFamily` | 字体，`""` 表示跟随系统 |
| `fontSize` | 当前行字号（预设档位 12–72，默认 40） |
| `playedColor` | 已播放 / 当前行颜色 |
| `unplayedColor` | 未播放颜色 |
| `showTranslation` | 是否显示翻译 |
| `showNextLinePreview` | 无翻译时显示下一行（仅 echo 布局） |
| `align` | `center` / `left` / `right` / `both`（交错） |
| `karaoke` | 逐词高亮（卡拉 OK 式平滑填充） |
| `karaokeColor` | 逐词高亮颜色 |
| `boldCurrent` | 当前行加粗（主程序默认关闭） |
| `lineHeight` | 行距 1.0–3.0（仅列表布局） |
| `backgroundOpacity` / `backgroundBlur` | 背景不透明度 / 模糊 |
| `alwaysOnTop` / `clickThrough` / `locked` | 置顶 / 鼠标穿透 / 锁定窗口位置 |

## 兼容性

依赖 `>=2.2.6-beta.20`（独立浮窗与 Now Playing 快照）。歌词行取 `lyric.lines[].text / translated`，翻译数据由主程序提供；逐字时间优先取 `lyric.lines[].characters[].startTime / endTime`（毫秒），缺失时按行时长与字数加权均分估算。
